Structurally Conditioned Diffusion:

Distance Filtering and the Reproduction of Skills-Based Stratification

Roberto Cantillan & Mauricio Bucca

Sociology | Pontificia Universidad Católica de Chile

I. THE PUZZLE

The Puzzle: Labor Market Dynamics & Persistent Inequality

  • Contemporary labor markets are characterized by unprecedented dynamism: technological advancements, globalization, and evolving industrial landscapes continually reshape the world of work [@kalleberg2011; @autor2015].

  • Despite this flux, foundational structures of occupational hierarchy and socio-economic inequality exhibit remarkable persistence and adaptive resilience [@tilly1998].

The polarization of the labor market

  • Demand for high-skill and low-skill jobs is increasing, while middle-skill jobs are declining. This is often referred to as job polarization.
  • This polarization is attributed to technological change and globalization, which devalue certain skills and revalue others.

The question

How does structurally conditioned skill diffusion generate distance-sensitive filtering mechanisms that systematically reproduce skills-based stratification within dynamic occupational markets?

Supply and Demand Dynamics

Individual Adaptation

“How do workers adapt to changing skill demands?”

  • Individual career decisions
  • Skill acquisition choices
  • Job search strategies
  • Human capital investment

Systemic Diffusion Processes

“How do systematic barriers shape skill adoption patterns?”

  • Systematic diffusion constraints
  • Compatibility requirements
  • Structural adoption logics
  • Independent of individual choices

Demand-Side Patterns Shape Supply-Side Possibilities

  • If skill diffusion follows structured patterns → diffusion opportunities are structurally predetermined

  • If different skill types have distinct diffusion logics → career destinies depend on skill type, not just skill possession

  • Implication: The skill diffusion process itself becomes a stratification engine that sorts workers into persistent hierarchies.

The Occupational Skill Space

  • We view the labor market as an “Occupational Skill Space”: A “Blau Space” where status dimensions (Education, Wages) position occupations as “niches”.

  • These niches are defined by skills—understood as key resources and nodes in a 2-mode network—whose diffusion dynamically (re)articulates boundaries and hierarchies.

Core Idea: From Static Structure to Dynamic Process

  • Previous Research: Shows WHAT the structure (e.g., polarization) looks like.

  • This Research: Reveals HOW boundaries are actively constructed and status is assigned. Through the lens of skill diffusion between occupations.

Central Insight:

Occupational boundaries and hierarchies aren’t just maintained—they’re dynamically (re)produced through differentiated skill adoption patterns on the demand side.

Theoretical Framework: Structurally Conditioned Diffusion

Research Question: How do structural conditions systematically filter skill diffusion across occupations to reproduce skills-based stratification?

Theorized Mechanism: Distance-Sensitive Filtering - occupational structures create systematic barriers that condition skill diffusion differentially by skill type

Empirical Pattern to Explain: “Trajectory Channeling” - structural conditioning produces systematic pathway differentiation between skill types

Distance-Sensitive Filtering: Core Theory

(How Structural Conditions Shape Diffusion Patterns)

Core Theory: Existing occupational structures systematically condition skill diffusion by creating distance-sensitive filtering effects that determine which skills can successfully diffuse across different occupational contexts.

Educational Distance Filtering

  • Educational Distance Filtering:
    • Occupational roles embed specific cognitive infrastructures and credential expectations.
    • Skills require compatible educational foundations for effective implementation and legitimacy. (e.g., analytical skills may require abstract reasoning capabilities that vary systematically across educational levels).

Economic Distance Filtering

  • Economic Distance Filtering:
    • Skills carry implicit value expectations that must align with occupational economic structures.
    • Economic misalignment between skill expectations and occupational compensation creates adoption barriers. (e.g., skills associated with high-value work may face implementation resistance in low-wage contexts).

Structural Distance Filtering

  • Structural Distance Filtering:
    • Skills must integrate with existing occupational skill profiles and workflows.
    • Structural compatibility determines feasibility of skill adoption across different occupational contexts. (e.g., certain skills may require complementary capabilities that vary across occupational structures).

Empirical Predictions: Basic Tests

Our approach: We test key predictions derived from the distance-sensitive filtering mechanism:

  • Distance Prediction: If distance-sensitive filtering matters, skill diffusion probability should systematically vary with educational, economic, and structural distances between occupations.

  • Skill Type Prediction: If filtering requirements differ by skill characteristics, we should observe systematic differences in how cognitive versus physical skills navigate distance barriers.

  • Trajectory Prediction: If distance filtering operates systematically, we should observe predictable channeling patterns that sort skills into distinct pathways.

  • Boundary Prediction: If filtering mechanisms operate, they should generate systematic boundary effects that reinforce occupational stratification patterns.

Hypothesis

Due to systematic filtering mechanisms, skill types will exhibit systematically different responses to occupational distances, creating predictable trajectory channeling patterns that actively reproduce occupational stratification.

II. METHODOLOGY

Data Source

  • We will use the O*NET database, which provides detailed information on job requirements, including skills, education, and wages.
  • We will also use the U.S. Census Bureau’s American Community Survey (ACS) to analyze labor market dynamics and occupational diffusion.
  • IPUMS-CPS data will be used to analyze the educational and occupational trajectories of individuals in the labor market.

Level of Analysis: Why Occupations?

  1. Data Foundation: O*NET is inherently designed to capture the generalized skill requirements that typify occupations across the economy, rather than firm-specific needs.

  2. Theoretical Rationale: Sociologically, occupations represent institutionalized roles with established skill expectations and shared understandings. Organizations primarily recruit into these pre-existing roles. Therefore, by focusing on occupations, we analyze the structural architecture of skill demand and its evolution – how types of work change – providing the essential context within which organizations operate and generate inequality.”

Study Steps

  • Step 1: Revealed Comparative Advantage (RCA) Calculation
    • Use “importance” variable of each skill for each occupation
    • Calculate RCA for years 2015 and 2023
    • RCA > 1 = occupation has “comparative advantage” in that skill (effective use)
  • Step 2: Skill Cluster Identification
    • Build skill complementarity networks
    • Apply Leiden algorithm for community detection
    • Result: 2 main clusters (consistent with Alabdulkareem et al.). Sociocognitive Skills (e.g., critical thinking, active listening) & Physical/Sensorimotor Skills (e.g., manual dexterity, arm-hand steadiness)
  • Step 3: Diffusion Events Construction
    • Positive Event (diffusion = 1): Target occupation adopts skill between 2015-2023 that source occupation already - had in 2015
    • Negative Event (diffusion = 0): Target occupation does NOT adopt the skill by 2023
    • Generate all possible source-target combinations for each skill

Study steps

  • Step 4: Occupational Distance Calculation
    • Educational Distance: Difference in average educational requirements between target and source occupation
    • Wage Distance: Difference in average income between target and source occupation
    • Structural Distance: Similarity in complete skill profiles between occupations (measured in 2015)
  • Step 5: Descriptive Analysis
    • Diffusion patterns by skill type
    • Socioeconomic diffusion matrices by quartiles
    • Differences in diffusion rates by distances
  • Step 6: Diffusion Model
    • Logistic Regression: P(Diffusion = 1) = f(Predictors): Skill type (Sociocognitive vs. Physical/Sensorimotor), Educational distance (target - source), Wage distance (target - source), Structural distance between occupations (2015 profiles)

Diffusion Model Specification

  • Dependent Variable: Skill diffusion probability from origin occupation \(o_1\) to target occupation \(o_2\)

\[ \text{logit}\left(P(D_{s, o_1 \to o_2} = 1)\right) = \beta_0 + \beta_1 \text{Skill Type}s + \\ \beta_2 \text{Ed. Distance}{o_1,o_2} + \beta_3 \text{Wage Distance}{o_1,o_2} + \beta_4 \text{Structural Distance}{o_1,o_2} + \mathbf{\gamma Z} \]

Key Predictors:

  • Skill Type: Sociocognitive vs. Physical/Sensorimotor (community detection)
  • Educational Distance: Difference in average educational requirements (target - source)
  • Wage Distance: Difference in average compensation (target - source)
  • Structural Distance: Cosine similarity of complete skill profiles (2015)

Controls (\(\mathbf{Z}\)):

  • Worker Flow: Probability of individual transitions between occupations (CPS data)
  • Industry Similarity: Shared industrial classifications and contexts
  • Occupation Size: Employment levels (controls for O*NET measurement reliability)

Model Features: Robust standard errors clustered by occupation pairs

IV. Discussion

Key Findings

Distance-Sensitive Filtering Confirmed:

  • Cognitive Skills (“The Escalator”): Show systematic upward diffusion driven by low distance barriers. Models confirm educational advancement and moderate structural flexibility enable boundary crossing.

  • Physical/Sensorymotor Skills (“The Lateral Drift”): Exhibit constrained lateral diffusion due to high distance barriers. Models verify structural proximity requirements and educational/wage constraints limit diffusion.

Systematic Filtering as Stratification Engine:

This distance-sensitive filtering mechanism—empirically confirmed by our models—operates as the core process that generates trajectory channeling and actively reproduces occupational polarization.

So What? - From Mechanism to Stratification Outcomes

Distance-Sensitive Filtering as Stratification Engine How micro-level filtering processes generate macro-level inequality:

  • Systematic Filtering: Occupational distances create predictable barriers that sort skills into distinct pathways
  • Trajectory Channeling: Differential distance sensitivity generates the “Escalator” vs “Lateral Drift” dynamics we observe
  • Boundary Reinforcement: Distance requirements systematically strengthen occupational divides and social closure

Observable Stratification Outcomes:

  • Predictable skill diffusion patterns that vary systematically by skill type
  • Self-perpetuating cycles of advantage and disadvantage through differential pathway access
  • Systematic reproduction of occupational hierarchies despite labor market dynamism

IV. Supporting material

Occupational - Skill Space

Occupational Skill Profiles:

  • Each occupation \(j\) is defined by a quantitative vector of O*NET skill importance/level values, \(\text{onet}(j,s)\), representing its reliance on each skill \(s\).

  • Intuition: This vector acts as a “skill fingerprint” for each occupation, detailing its specific demands.

Revealed Comparative Advantage (RCA):

  • Purpose: Measures an occupation’s relative specialization in a skill compared to the system average.

  • Calculation: For skill \(s\) in occupation \(j\):

\[\text{rca}(j,s) = \frac{\text{onet}(j,s) / \sum_{s' \in S} \text{onet}(j,s')}{\sum_{j' \in J} \text{onet}(j',s) / \sum_{j' \in J, s'' \in S} \text{onet}(j',s'')}\]

Where:

  • Numerator: Skill \(s\)’s share of occupation \(j\)’s total skill requirements
  • Denominator: Skill \(s\)’s share of the entire economy’s skill requirements
  • Interpretation: \(\text{rca}(j,s) > 1\) indicates occupation \(j\) uses skill \(s\) more intensively than the economy average

Occupational - Skill Space II

Interpretation:

  • \(\text{rca}(j,s) > 1\): Occupation \(j\) has a comparative advantage in skill \(s\); the skill is “overexpressed” or “effectively used” (denoted \(e(j,s)=1\)). This highlights skills that distinctively characterize the occupation.

  • \(\text{rca}(j,s) \leq 1\): The skill is not a distinctive specialty for occupation \(j\) relative to the average.

  • Benefit: Normalizes raw O*NET scores to filter out ubiquitous skills and spotlight an occupation’s key distinguishing skill requirements.

Skill Networks

Clusters (skill_type):

Skill-Skill Complementarity Network (Skillscape): A network is constructed where nodes are skills. The weight of an edge between two skills, \(\theta(s,s')\), represents their complementarity. This is calculated as the minimum of the conditional probabilities that both skills are effectively used together in the same occupations:

\[\theta(s,s') = \frac{\sum_{j \in J} e(j,s) \cdot e(j,s')}{\max\left(\sum_{j \in J} e(j,s), \sum_{j \in J} e(j,s')\right)}\]

This captures how skills support each other, either by boosting productivity or through ease of simultaneous acquisition.

Louvain Community Detection: This unsupervised algorithm is applied to the skill complementarity network to identify clusters of skills (skill types). It works by greedily optimizing modularity, comparing the density of connections within a community to that between communities, without pre-specifying the number of clusters.

Identifying Diffusion Events (diffusion = 1)

  • Core Idea: A skill diffuses from an occupation already using it (source) to an occupation that newly adopts it (target) between a start_year and end_year.

  • Process:

    1. Effective Skill Use: Determine if a skill is “effectively used” in each occupation for both start and end years (Revealed Comparative Advantage - RCA > 1).
    2. Identify Sources: List occupations effectively using the skill in the start_year.
    3. Identify New Adopters (Targets): List occupations effectively using the skill in the end_year BUT NOT in the start_year.
    4. Positive Event: For a given skill, a positive diffusion event (diffusion = 1) is created for every pair of (source occupation, new adopter target occupation).

Constructing Non-Diffusion Events (diffusion = 0)

  • Core Idea: A skill does not diffuse from a source occupation to a target occupation if the target fails to effectively use the skill by the end_year.

  • Process:

    1. Effective Skill Use & Sources: Same as for positive events (RCA > 1 in start_year for sources).
    2. Identify Potential Non-Adopters (Targets): List all relevant occupations that are NOT effectively using the skill in the end_year.
    3. Negative Event: For a given skill, a negative diffusion event (diffusion = 0) is created for every pair of (source occupation, potential non-adopter target occupation).
    4. Exhaustive Generation: The script generates all such possible negative (non-diffusion) events.

Addressing Causal Identification

Key Challenge: “How do we know skills drive occupational changes vs. reverse?”

Our Design Response:

  • Temporal Focus: Track movement of existing skills (2015 baseline) between occupations, not creation of new skill requirements
  • Mechanism Specificity: Theory focuses on how existing occupational structures filter skill diffusion, not skill creation of new occupational categories
  • Pattern Evidence: Systematic filtering by skill type suggests structural conditioning rather than random organizational change
  • Future Identification: Technology shocks, geographic instruments, and staggered adoption for stronger causal inference
